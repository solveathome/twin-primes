## 2. The due OEIS check: one loud HIT (the pair-count object is owned), the gap objects absent

Channel: `oeis.org/search?fmt=text`, calibrated in-session (known positives
`2,6,18,30,66,150,192,258` → A288815 and `2,4,6,10,14,22,26,34,40,46,58,66`
→ A048670, both returned first query). Sequence values generated by a
15-line mirror of zonegap-01's conventions and cross-checked against its
embedded output (envelope-step p's, band headmax, min count) before
searching. Full query log:
session scratchpad `oeis-batch-results.txt`, 33 queries.

**THE HIT — the pair-count-per-zone sequence is in OEIS, one index over.**
Query `4,8,9,16,17,21,29,30,41,48,50,61,74,87` (our per-zone counts from
p = 5) returns **A273257, "Number of twin primes between prime(n) and
prime(n)^2"** (Jesse H. Crotts, Aug 2016; b-file to n = 10000 by Greathouse).
The match is no coincidence: since (p, p′) contains no prime, the twin
openers in our zone (p, p′²) are exactly those in [p′, p′²), so **our
per-zone pair count at p_n equals A273257(n+1) for every n ≥ 2** (only the
p = 2 zone differs, via their disjoint-pairs rule at (3,5),(5,7); upper
endpoints cannot differ because a+2 = p′² is impossible). The family around
it, all read in full internal format:

- **A057767** (Nomoto, Oct **2000**): twin pairs between P(n)² and P(n+1)² —
  the count companion of A091591/A091592, with Hasler's 2019 comments:
  "a(n) > 0 for infinitely many n" ⟺ TPC, a conjectured record-low ladder
  each term of which would imply TPC, and the empirical lower bound
  a(n)/n ≳ 1/11 (quoted into A273257 as "about n/11").
- **A308777** (Michel Marcus, Jun 2019): twin PRIMES (members, not pairs)
  between p and p², inclusive; links Birdsey–Schay, arXiv:1906.09220, "A
  Sieve for Twin Primes" (2019) — a paper attached to exactly this window.
- **A143738** (2008): twin pairs between n and n² for ALL n (openers
  counted); A079047: plain primes between prime(n) and prime(n)².

**Novelty-position change, stated loudly:** the zone's **pair-count**
object is OWNED — at window (p, p²) it has been in OEIS since 2016 and our
per-zone count sequence is A273257 shifted by one index; at squares-to-
squares windows since 2000, with the TPC-equivalence and a linear-growth
observation already recorded there by Hasler in 2019. Any zone-count claim
